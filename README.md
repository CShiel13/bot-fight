## Quick Start

1. Install [Ollama](https://ollama.com) and pull a model:
ollama pull phi3


2. Install the Python dependency:
pip install ollama


3. Run the debate:
python bot-fight.py "Is a hot dog a sandwich?"


Omit the topic to use the default.

See `sample-transcript.txt` for a full example debate.

## System Requirements

This runs a local AI model. A modern CPU with at least 8 GB of RAM is recommended. Older or low-spec machines may see slow responses or instability.
